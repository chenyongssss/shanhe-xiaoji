# 山河小记分阶段部署计划

## 阶段 1：静态部署

- 保留当前本地优先的地图编辑体验。
- 通过 `package.json` 提供统一的 `npm run build` 验证入口。
- 通过 `vercel.json` 支持静态托管、分享页路由和基础安全响应头。

## 阶段 2：账号与云同步

- 接入 Supabase Auth、Postgres 和 Storage。
- 将 `localStorage` 的地图状态迁移到用户默认地图。
- 离线或未配置云端时继续使用本地模式。

## 阶段 3：隐私分享

- 分享链接由服务端 token 管理，而不是把完整数据放进 URL。
- 分享页仅返回公开字段，默认隐藏私密正文与原图。
- 分享链接支持过期、撤销和权限变更。

## 阶段 4：协作

- 地图成员支持 owner、editor、viewer 三种角色。
- editor 可以添加城市、更新路线和上传协作素材。
- Realtime 订阅城市状态变化，操作日志保留审计线索。

## 阶段 5：产品化

- 支持公开主页、自定义主题、图片 CDN 缩略图和数据导出。
- 增加账号删除、地图归档和更多合规设置。
